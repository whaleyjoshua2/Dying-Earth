# 2026-09-23: version 0.09.0, the production version

The dev diary for version 0.09.0, charted as wayfinder map
[#331](https://github.com/whaleyjoshua2/Dying-Earth/issues/331). As 0.08.8's, this folder is a
record of the **build**: one folder per ticket, written as each was resolved, holding the pictures,
the specifications and the measurements that decided it. The rules as decided are in
[`docs/spec/version-0.09.0.md`](../../spec/version-0.09.0.md), written by the closing ticket.

This is the first version since 0.06.0 to reach into the economy and the first ever to change what
a build costs, so more of this folder is sweeps than usual: every rule ticket was measured against
the 0.08.8 baseline as it landed, and `ticket-332-widgets/sweeps/` holds the probe that found why
the win column moved.

**Every folder here is listed.**
