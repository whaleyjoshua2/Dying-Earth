# 2026-09-25: version 0.09.2, the tidy-up version

The dev diary for version 0.09.2, charted as wayfinder map
[#365](https://github.com/whaleyjoshua2/Dying-Earth/issues/365). As 0.09.1's, this folder is a record
of the **build**: one folder per ticket, written as each was resolved, holding the pictures,
specifications and measurements that decided it. The rules as decided are in
[`docs/spec/version-0.09.2.md`](../../spec/version-0.09.2.md), a section per ticket.

The baseline every sweep here is read against is 0.09.1's closing sweep,
[`../2026-09-24-version-0.09.1/sweeps/final-0.09.1.txt`](../2026-09-24-version-0.09.1/sweeps/final-0.09.1.txt):
**6 / 28 / 3 / 2**, collapses 41 of 80. Read the per-Faction totals at the foot of a sweep file,
never the per-seating arrays.
