# 2026-09-22: version 0.08.8, the campaign version

The dev diary for version 0.08.8, charted as wayfinder map
[#316](https://github.com/whaleyjoshua2/Dying-Earth/issues/316). As 0.08.7's, this folder is a
record of the **build**: one folder per ticket, written as each was resolved, holding the pictures
and the measurements that decided it. The rules as decided are in
[`docs/spec/version-0.08.8.md`](../../spec/version-0.08.8.md), written by the closing ticket.
