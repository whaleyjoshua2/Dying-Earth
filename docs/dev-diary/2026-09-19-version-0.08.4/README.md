## What the pictures changed

Three times in this version a picture found something reading the code had not:

- **The founding button had never had glyphs**
  ([#258](https://github.com/whaleyjoshua2/Dying-Earth/issues/258)). The ticket said it already
  did; the designer insisted it *"needs yeilds"*; the first picture of it agreed with the designer.
- **A second challenger line, five versions stale**
  ([#262](https://github.com/whaleyjoshua2/Dying-Earth/issues/262)). Ticket #75's top-of-card
  warning named the highest Standing and priced the place by a rule ticket #60 replaced. It had sat
  above every held card since 0.05.
- **The Colony colour** ([#255](https://github.com/whaleyjoshua2/Dying-Earth/issues/255)) was
  found by the designer's own eye before the map was charted, and confirmed by a picture while
  charting.

## And what the measurements changed

- **Blame credit was redefined** because ten games of ten showed nobody had ever held one
  ([#265](https://github.com/whaleyjoshua2/Dying-Earth/issues/265)).
- **The decay rule became a step rule** because a multiplier rounded to a whole number could only
  bite at the cap ([#266](https://github.com/whaleyjoshua2/Dying-Earth/issues/266)).
- **The `sim` example printed Blame in ppm all along**, which the map's Notes had said nothing did;
  the carbon-credit and Smear tickets priced against it from day one.
