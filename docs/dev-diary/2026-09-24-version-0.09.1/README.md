# 2026-09-24: version 0.09.1, the plain-speaking version

The dev diary for version 0.09.1, charted as wayfinder map
[#342](https://github.com/whaleyjoshua2/Dying-Earth/issues/342). As 0.09.0's, this folder is a record
of the **build**: one folder per ticket, written as each was resolved, holding the pictures,
specifications and measurements that decided it. The rules as decided are in
[`docs/spec/version-0.09.1.md`](../../spec/version-0.09.1.md), written by the closing ticket.

The designer's list came mostly from 0.09.0's first real playtest
([`../2026-09-24-playtest-0.09.0/`](../2026-09-24-playtest-0.09.0/README.md)). The second half of the
version is work the build itself uncovered, most of it measured with a throwaway diagnostic first
and only then decided.
