Dying Earth on Linux
--------------------
1. Unzip the folder anywhere. Keep "dying-earth" and the "assets" folder together.
2. Open a terminal in the folder and run:   ./dying-earth
   (If it says "Permission denied":   chmod +x dying-earth   then try again.)
3. Built on Ubuntu 22.04; needs a 64-bit Ubuntu 22.04 or newer (or another distribution
   with glibc 2.35 or newer), a desktop session (X11 or Wayland), and a GPU with Vulkan.
   If the window does not open, install:   sudo apt install libasound2 libudev1 libvulkan1
4. Saves go to ~/.local/share/DyingEarth/data/saves (there is a Load button on the title screen).
